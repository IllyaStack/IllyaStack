# SMarket — My Contribution to the Diploma Team Project

**Role: Full-Stack Developer (frontend ownership + selected backend services)**  
**Project:** [ItStepDiplomaTeam1/smarket](https://github.com/ItStepDiplomaTeam1/smarket)

SMarket is a price-comparison platform built as a microservices-based system. The team repository documents a React/TypeScript frontend and services across Python, Go and Rust, with supporting data and infrastructure components.

## My contribution

As part of the IT STEP diploma team, I was responsible for developing the **entire frontend** and also contributed to backend development:

- Developed and maintained the application's frontend.
- Connected the frontend to backend functionality and service APIs.
- Personally implemented **some backend microservices**.
- Frequently adjusted existing backend services to align their behaviour and data contracts with frontend requirements.
- Worked across frontend–backend boundaries to resolve integration issues.

These contribution details are based on my own description of my role. I have not listed specific microservice names or individual commits here without verifying their authorship.

## Project architecture — team-level context

The shared repository describes:

- **Frontend:** React and TypeScript.
- **Backend:** Microservices in Python (FastAPI), Go and Rust.
- **Data and infrastructure:** PostgreSQL, MongoDB, Redis, Meilisearch, RabbitMQ and Docker.
- **Product concept:** Search and compare supermarket products and prices, with an AI-assisted experience.

> The overall architecture and its features are **team achievements**. My individual responsibilities are described separately above.
